# سبزدارو — بستهٔ کامل پروژه

```
frontend/   رابط فروشگاه (HTML + CSS + JS)
backend/    API آزمایشی و نسخهٔ تولیدی Next.js + Prisma
backend/prisma/schema.prisma   مدل دیتابیس
backend/scripts/               preflight، migration bootstrap و cron
 docs/                         قرارداد API و معماری
 tests-e2e/                    تست‌های API و رابط
```

## نمایش سریع دمو

با Node.js 18 یا جدیدتر:

```bash
node backend/dev-server/server.js
```

سپس `http://localhost:4000` را باز کنید. در این حالت داده‌ها آزمایشی‌اند، OTP در کنسول سرور چاپ می‌شود و پرداخت شبیه‌سازی است؛ از این روش برای فروش واقعی استفاده نکنید.

## نسخهٔ واقعی و انتشار

راهنمای کامل در [`DEPLOY-PRODUCTION.md`](DEPLOY-PRODUCTION.md) است. نسخهٔ واقعی از Next.js، PostgreSQL و Redis استفاده می‌کند. قبل از فروش باید migration دیتابیس تولید شود، build واقعی موفق شود، مقادیر `.env` با سرویس‌های شما تنظیم شوند و پرداخت/OTP در حساب واقعی آزمایش شود.

تست مستقل قرارداد API:

```bash
node tests-e2e/api_test.js
```

## دادهٔ نمونه و موارد بیرون از کد

کالاها، قیمت‌ها، موجودی، برندها و نظرات نمایشی‌اند. `npm run seed` دادهٔ پایه و مدیر اولیه را می‌سازد، نه کاتالوگ واقعی فروش؛ اطلاعات واقعی باید از پنل مدیریت اضافه شوند. مجوزها و تعهدات قانونی فروش متناسب با نوع کالاها و محل فعالیت باید جداگانه بررسی شوند.
