# تست‌های end-to-end و قرارداد

همان تست‌هایی که پیش از تحویل اجرا شد. پیش‌نیاز: Node ≥ 18، Python 3 با `pip install playwright && playwright install chromium`.

| فایل | چه چیزی را تست می‌کند | نتیجهٔ تحویل |
|---|---|---|
| `node api_test.js` | قرارداد API روی dev-server با HTTP واقعی | ۸۶/۸۶ |
| `python3 live_e2e.py` | کل فرانت‌اند ↔ سرور در Chromium (OTP، سبد، کوپن، پرداخت ناموفق/موفق، حساب، پنل مدیریت، RBAC) با CSP سخت‌گیرانه | ۵۴/۵۴ |
| `python3 smoke.py` | حالت نمایشی (بدون سرور): کاروسل، منو، تم، افزودن به سبد، پرداخت | ۳۶/۳۶ |
| `python3 audit_all.py` | ۱۵ صفحه × ۱۱ عرض × موبایل/دسکتاپ: هیچ سرریز افقی | ۰ سرریز از ۲۴۰ |
| `python3 dlg.py` | دکمه‌های داخل دیالوگ در حالت نمایشی | ✓ |
| `npx tsx pure_backend_tests.ts` | منطق خالص بک‌اند (حراج، انتقال وضعیت، HMAC، درگاه آزمایشی، بلوک‌شدن آن در production) | ۱۹/۱۹ |

مسیرهای Next.js/Prisma را این تست‌ها **اجرا نمی‌کنند** (به دیتابیس واقعی نیاز دارند) — راهنمای تست آن‌ها در `backend/README.md`.


برای استفاده از Chromium نصب‌شده در مسیر سفارشی: `CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium`. برای تست UI استاتیک، اگر مرورگر دسترسی به `file://` را مسدود می‌کند، فرانت‌اند را روی HTTP محلی سرو کنید و `FRONTEND_URL=http://127.0.0.1:8013/index.html` تعیین کنید؛ این دو متغیر اختیاری‌اند و مقدار پیش‌فرض تست‌ها را تغییر نمی‌دهند.
