# سبزدارو — گزارش آماده‌سازی برای انتشار

تاریخ: ۲۸ اکتبر ۲۰۲۶

این بسته روی یک کپی از فایل ورودی آماده شده است؛ فایل ZIP اصلی تغییر نکرده است.

## اصلاحات اعمال‌شده

- درگاه نمونه در حالت `NODE_ENV=production` رد می‌شود و نام درگاه ناشناخته نیز پذیرفته نمی‌شود.
- درخواست و تأیید زرین‌پال دارای بررسی مبلغ، timeout و کنترل پاسخ API است؛ مبالغ داخلی پروژه تومان‌اند و قبل از ارسال به زرین‌پال به ریال تبدیل می‌شوند.
- پیامک کنسولی در production ممنوع است؛ برای کاوه‌نگار، کلید API و نام قالب OTP الزامی است و کد ورود در لاگ چاپ نمی‌شود.
- پاسخ‌های نامعتبر JSON در مسیرهای ورود با خطای کنترل‌شده پاسخ داده می‌شوند.
- سلامت سرویس، PostgreSQL و Redis را بررسی می‌کند.
- callback پرداخت برای رقابت درخواست‌های هم‌زمان و پرداختی که پس از منقضی/لغوشدن سفارش تأیید شود محافظت شده است؛ مورد دیرهنگام به‌صورت بازپرداخت نیازمند بررسی دستی ثبت می‌شود.
- پیش‌بررسی تنظیمات production، اسکریپت cron آزادسازی موجودی سفارش‌های منقضی، Dockerfile، Compose، نمونه Nginx و راهنمای انتشار اضافه شده‌اند.
- تست‌های جدید برای ردکردن درگاه نمونه در production و رفتار سرویس پیامک اضافه شده‌اند.

## بررسی‌هایی که در این محیط انجام شدند

- تست قرارداد API موجود: ۸۶ موفق، ۰ ناموفق. این تست‌ها روی سرور دمو/قرارداد موجود اجرا می‌شوند؛ جای اجرای نسخهٔ Next.js و دیتابیس production را نمی‌گیرند.
- بررسی نحوی TypeScript/TSX: تعداد ۸۲ فایل، بدون خطای نحوی در transpilation.
- `node --check` برای فایل‌های JavaScript و کامپایل نحوی فایل‌های Python: بدون خطا.

## مواردی که هنوز تأیید نشده‌اند

- `npm install` در محیط آماده‌سازی به خطای شبکه (`EAI_AGAIN` برای npm registry) رسید؛ بنابراین `npm run typecheck`، تست‌های Vitest و `npm run build` با وابستگی‌های واقعی دوباره اجرا نشده‌اند.
- مرورگر خودکار در این محیط به‌دلیل محدودیت محیط اجرا نتوانست تست تازه‌ای انجام دهد.
- migration اولیه Prisma عمداً حدسی یا دستی ساخته نشده است. پس از نصب وابستگی‌ها، فقط برای یک دیتابیس کاملاً خالی، طبق `DEPLOY-PRODUCTION.md` آن را تولید و بازبینی کنید.
- اتصال واقعی زرین‌پال، کاوه‌نگار، PostgreSQL/Redis روی سرور، دامنه، SSL و cron به اطلاعات و دسترسی واقعی نیاز دارند و از داخل این ZIP قابل فعال‌سازی نیستند.
- کاتالوگ دمو، قیمت‌ها، موجودی، هزینه و عنوان ارسال و محتوای حقوقی باید با اطلاعات واقعی کسب‌وکار جایگزین/بررسی شوند.

## پیش از دریافت سفارش واقعی

راهنمای `DEPLOY-PRODUCTION.md` را کامل اجرا کنید؛ Build و typecheck موفق، migration بازبینی‌شده، پیامک OTP واقعی، پرداخت آزمایشی واقعی، آزادشدن موجودی، پنل مدیر و backup/restore باید روی سرور نهایی تأیید شوند.
